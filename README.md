# Command Node Hub | Showcase Edition 50

**Explore a network command center with three fictional environments and 69 devices.** Tour animated topology, historical monitoring, logs, alerts, and network documentation. Built by **DSR Technologies**.

## Download and explore

[**Download the Windows Showcase Edition**](https://github.com/Jakedoege/CommandNodeHub-Showcase/releases/tag/v50-showcase)

Extract the complete ZIP and open **CommandNodeHub-Showcase.exe**. Keep the bundled runtime beside the executable. Select **Showcase guide** for a walkthrough, **Map controls** for the full topology editor, and **Pause simulation** to hold measurements during a presentation.

The demo starts with synthetic inventory, events, credentials, and metric history in a dedicated local profile. Live connections are disabled.

## Three environments

| Environment | Explore |
| --- | --- |
| Meridian HQ | Workplace devices, gateways, core/access switches, wireless infrastructure, compute and storage |
| Prism Homelab | Virtualization-focused inventory, saved maps, history, and the Violet theme |
| Harbor Edge | A separate site with its own workspace and Lagoon theme |

Each environment contains **23 devices**, **22 documented connections**, and four bookmarked map views.

## Topology you can work with

Follow animated connections between gateways, switches, servers, workstations, access points, cameras, and other devices. Pan, zoom, drag devices, and organize freeform sections. Inspect endpoint ports, latency labels, connection styles, and device details. Jump among the full environment, compute/storage, workplace, and network fabric bookmarks. Experiment with curved or straight wires, vendor icons, circular cards, saved layouts, and undo.

## Read the signals

Explore historical **CPU, RAM, storage, throughput, temperatures, fan speed, and power**. Change time ranges, compare devices, inspect interfaces, and investigate the simulated camera outage. The **Collectors & relays** view displays synthetic switch port state, speed, VLANs, counters, and traffic rates.

## Trace events in Log Hub

Search sample Syslog, filter by device/source/severity/time, inspect event details, review deterministic rule findings, and keep records for follow-up. The fictional events cover interface changes, account lockouts, backup completion, and collector synchronization.

## Document the network

Export **PDF and CSV** reports or a documentation package. Explore physical connections with source/destination ports, printable topology, hardware inventory, IP/VLAN details, credential assignment metadata, configuration snapshot history, and cable labels for documented endpoints.
